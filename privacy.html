Політика конфіденційності

Оновлено 25 листопада 2026 року.

Застосунок «Діана» — приватний помічник однієї людини (власника). Він не є публічним сервісом і не призначений для інших користувачів.

Які дані використовуються

  • Gmail — застосунок читає листи у власній скриньці помічника, позначає їх і надсилає листи від імені власника.
  • Google Drive / Таблиці — лише файли, які створив сам застосунок (таблиця витрат). Інших файлів на Диску він не бачить.

Де зберігаються дані

Ключі доступу Google і дані зберігаються лише на власному комп'ютері власника. Дані не продаються, не передаються третім особам і не використовуються для реклами.

Обмежене використання

Використання й передача інформації, отриманої через API Google, відповідає Google API Services User Data Policy, зокрема вимогам Limited Use.

Як відкликати доступ

Доступ можна будь-коли відкликати на сторінці myaccount.google.com/permissions. Після цього застосунок втрачає доступ, а збережені ключі видаляються з комп'ютера власника.

Privacy Policy (English)

“Diana” is a private assistant used by a single person (the owner); it is not a public service. It uses Gmail (read, label and send mail in the assistant's own mailbox) and Google Drive/Sheets limited to files the app itself created (a cost spreadsheet). Access tokens and data are stored only on the owner's own computer; data is never sold, shared with third parties or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
